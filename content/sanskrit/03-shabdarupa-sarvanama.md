# Sanskrit Chapter 3 — शब्दरूप एवं सर्वनाम

## Learning objectives

The student should be able to recognise noun forms by **लिङ्ग, वचन and विभक्ति**, identify common declension patterns, and use pronouns while translating Ayurveda passages.

## 1. The three things to ask of a noun

Whenever you see a Sanskrit noun, ask:

**What is the stem? → What is the gender? → What is the number/case?**

For example, **देहे**:
- base: देह
- gender: masculine
- form: locative singular
- meaning: in/on the body

## 2. लिङ्ग

Three grammatical genders:

- पुल्लिङ्ग
- स्त्रीलिङ्ग
- नपुंसकलिङ्ग

Gender is grammatical and cannot always be predicted from English meaning.

## 3. वचन

- एकवचन — one
- द्विवचन — two
- बहुवचन — more than two

Sanskrit preserves the dual, which is frequently encountered in classical texts.

## 4. विभक्ति

| विभक्ति | Core question/use |
|---|---|
| प्रथमा | who/what as subject |
| द्वितीया | object/destination |
| तृतीया | instrument/means/association |
| चतुर्थी | recipient/purpose |
| पञ्चमी | separation/source |
| षष्ठी | relation/possession |
| सप्तमी | location/context |
| संबोधन | addressing |

**Important:** विभक्ति and कारक are related but not identical concepts. A विभक्ति is a grammatical case ending/form; कारक describes a semantic relation.

## 5. Model declension: राम

| Case | Singular | Dual | Plural |
|---|---|---|---|
| प्रथमा | रामः | रामौ | रामाः |
| द्वितीया | रामम् | रामौ | रामान् |
| तृतीया | रामेण | रामाभ्याम् | रामैः |
| चतुर्थी | रामाय | रामाभ्याम् | रामेभ्यः |
| पञ्चमी | रामात् | रामाभ्याम् | रामेभ्यः |
| षष्ठी | रामस्य | रामयोः | रामाणाम् |
| सप्तमी | रामे | रामयोः | रामेषु |
| संबोधन | हे राम | हे रामौ | हे रामाः |

This pattern is a model. Students should learn the pattern and then apply the same logic to Ayurveda vocabulary.

## 6. Ayurveda nouns worth practising

- दोष
- रोग
- देह
- अग्नि
- वायु
- रस
- धातु
- मनस्
- ओजस्
- स्रोतस्
- आहार
- औषध

Some of these follow different declension patterns. Do not force every noun into the राम pattern.

## 7. सर्वनाम

Important pronouns:

- अहम् — I
- आवाम् — we two
- वयम् — we
- त्वम् — you
- युवाम् — you two
- यूयम् — you plural
- सः / सा / तत् — he/she/that
- एषः / एषा / एतत् — this
- यः / या / यत् — who/which
- कः / का / किम् — who/what

### Relative-correlative pattern

One of the most important reading structures:

**यः ... सः ...**  
**यत् ... तत् ...**  
**या ... सा ...**

Example:
**यः दोषः प्रकुपितः सः रोगस्य कारणं भवति।**

Meaning: The aggravated doṣa becomes a cause of disease.

Do not translate word-by-word before identifying the paired structure.

## 8. Practical parsing method

For any noun:

**देहे**

1. find the stem: देह-
2. recognise ending: -े
3. infer case/number from context: सप्तमी एकवचन
4. ask its syntactic role
5. translate naturally: “in the body”

## Practice

Parse these:
- देहे
- दोषस्य
- रोगेण
- धातूनाम्
- स्रोतसि

Then identify the likely meaning in an Ayurveda sentence.

### Exam focus

Be able to distinguish:
**प्रथमा vs द्वितीया**, **तृतीया vs पञ्चमी**, **षष्ठी vs सप्तमी**, and singular/dual/plural.

### Memory rule

**Ending is evidence, context is confirmation.**
