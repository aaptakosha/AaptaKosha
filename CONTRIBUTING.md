# Contributing to AaptaKosha

Thank you for helping improve AaptaKosha.

## Academic-content contributions

For Samhita content, preserve source fidelity. Clearly separate:
- original Sanskrit text
- faithful Hindi/English translation
- explanatory material
- Tika/commentary translation
- NCISM-required recitation scope

Do not invent shloka text, chapter numbering, or source attribution.

## Code contributions

1. Fork the repository and create a focused branch.
2. Keep changes small and explain the user-facing impact.
3. Run the repository's affected tests and the frontend audit.
4. Verify changed API and frontend routes.
5. For curriculum changes, verify NCISM source/version metadata.
6. Open a pull request using the repository template.

## Pull requests

Include:
- what changed
- why it changed
- verification performed
- content/source references where applicable
- screenshots for significant UI changes

## Licensing

Source code is released under the repository LICENSE. Do not assume third-party, classical, translated, or publisher-specific content is covered by that code license.
