# AaptaKosha Samhita Library

## Purpose

A dedicated, searchable classical-text area where students can find major and lesser-known Ayurvedic texts without having to know which BAMS year contains them.

## Discovery filters

- Professional: 1st / 2nd / 3rd
- Exam: AIAPGET
- Collection: Brihattrayi / Laghutrayi / Other classical / Later compendia / Nighantu
- Text
- Sthana / Skandha / section
- Adhyaya
- Topic
- Commentary
- Language
- Content type

## Important classification rule

Not every important Ayurvedic work is technically a Samhita. AaptaKosha therefore uses a broader Classical Text Library internally while presenting Samhita Library as the student-facing discovery section. This permits compendia and nighantus to be included without incorrectly labelling them as Samhitas.

## Student views

### 1st Professional
Foundational Samhita reading and classical-text methodology.

### 2nd Professional
Texts and chapters connected to Samhita Adhyayan-2 and clinical/basic principles.

### 3rd Professional
Samhita Adhyayan-3 and clinically oriented classical references.

### AIAPGET
A cross-year view for verified classical-text facts, terminology, chapters, authors/commentators and tested concepts.

### All Samhitas
A complete searchable catalogue independent of professional year.
