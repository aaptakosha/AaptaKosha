## Registry rules

1. Prefer official NCISM sources over secondary copies.
2. Record document/version metadata whenever available.
3. Do not silently overwrite an older authoritative record; mark supersession explicitly.
4. Curriculum-derived records should retain a provenance link to the source entry.
5. Re-verification should record the verification date even when the source URL is unchanged.

This is an initial baseline, not a claim that these pages exhaust every NCISM document required by the final system.
