# NCISM BAMS curriculum source baseline

AaptaKosha treats NCISM as the academic source of truth and records the source/version used for curriculum mapping.

## Current official sources reviewed

- NCISM first-professional BAMS curriculum index: https://ncismindia.org/I-year-syllabus.php
- NCISM First Professional Samhita Adhyayan 1: https://www.ncismindia.org/Ay%20UG-SA1-1.pdf
- NCISM Padartha Vijnanam: https://ncismindia.org/AyUG-PV-1.pdf
- NCISM Ayurpraveshika transitional curriculum (2025-26 onward): https://ncismindia.org/assets/pdf/Ayurpraveshika%20Transitional%20Curriculum%20for%20BAMS.pdf
- NCISM BAMS academic calendar for the 2025-26 batch: https://ncismindia.org/assets/pdf/ACADEMIC%20CALENDAR%20UG%20PROGRAM.pdf

## Versioning rule

Curriculum records should carry the NCISM curriculum identifier and version/year where available. A change in NCISM source material must produce a new reconciliation/migration rather than silently overwriting an existing academic snapshot.

## Important distinction

The 2025-26 Ayurpraveshika document is a transitional/induction curriculum and is not a replacement for the professional-subject curriculum. The current academic calendar describes the 2025-26 first professional as an 18-month phase from 1 November 2025 through 30 April 2027.

## Content-quality gate

For every mapped subject/chapter, contributors should verify:
1. NCISM subject code.
2. Professional year.
3. Chapter/topic code where supplied by NCISM.
4. Course outcome/competency where supplied.
5. Must-know/know-how/skill classification where supplied.
6. Teaching-learning and assessment method where supplied.
7. Source PDF/version/date.

Do not infer a competency code when the authoritative NCISM source does not provide one.
